# MasterSync — versões

Instaladores do **MasterSync** (antigo AutoSync), que sincroniza os vídeos da câmera com o áudio externo dentro do Final Cut Pro.

- **Instalar:** baixe o `.dmg` da versão mais nova em [Releases](https://github.com/Final-Cut-Apps/autosync-releases/releases) e siga o "Como instalar.txt".
- **Atualizar:** o MasterSync se atualiza sozinho (Ajustes › Atualizações). Aqui fica só a versão atual; as anteriores são guardadas de forma privada.

Requer Mac com Apple Silicon e macOS 15 ou mais novo. O código do app não fica aqui.
