# AutoSync — versões

Instaladores do **AutoSync**, que sincroniza os vídeos da câmera com o áudio externo dentro do Final Cut Pro.

- **Instalar:** baixe o `.dmg` da versão mais nova em [Releases](https://github.com/Final-Cut-Apps/autosync-releases/releases) e siga o "Como instalar.txt".
- **Atualizar:** o AutoSync se atualiza sozinho (Ajustes › Atualizações). Esta página guarda todas as versões, para baixar à mão ou voltar a uma anterior.

Requer Mac com Apple Silicon e macOS 15 ou mais novo. O código do app não fica aqui.
